# 视频站 GA4 统计口径

| 事件 | 触发事实 |
| --- | --- |
| sign_up | 创建10分钟内的新账号首次被当前浏览器看到，不等同于每次登录 |
| login | 邮箱认证、Google One Tap成功，或本标签明确发起Google登录后10分钟内返回已登录状态 |
| upload_success / upload_failed | 图片上传API成功/失败，不含选图本地校验失败 |
| generate_video | 生成API返回已创建的任务，保留历史事件名称 |
| generation_success / generation_failed | 当前浏览器在同意统计后创建的任务，其最终状态被前端读取 |
| video_download_click | 首页或账户页下载链接被点击，不保证传输完成 |
| begin_checkout / purchase | 原有结账创建/首次读到已付款订单 |

结果事件通过本地任务号去重，保留7天、最多50条。任务号仅存浏览器，不传GA。旧任务不补报；浏览器关闭期间完成的任务要在返回账户页读取后才能上报。清理存储、跨设备、并发标签或未返回页面可能导致遗漏/重复，生成成功率以服务端数据为准。未接受统计、拒绝、撤回和明确排除时不排队业务事件，不追溯补发。不得向GA传邮箱、文件名、媒体URL、提示词、背景描述或原始服务商错误。

## 登录回流与调试

- 首次加载若referrer主机精确为 `accounts.google.com`，GA config使用 `ignore_referrer=true`；本站归因Cookie同样忽略它。不忽略Google搜索或其他相似主机。
- 调试前打开本站 `/?analytics=off`（中文入口也可），在该浏览器本站localStorage保存 `analytics.excluded=1`，不加载GA并禁用本站Measurement ID。恢复用 `/?analytics=on`，仍须获得统计同意。不按代理IP或国家过滤。
- 开关仅排除该浏览器该域名的未来GA数据，不清理历史数据，不影响站内运营账本或访问接口，不自动排除其他设备。
- GA后台关键事件、自定义维度与过滤器是独立配置，代码上线不等于已登记。0关键事件不能解释为没有业务动作。

## 验收和分析

按实际授权选择构建、受控页面检查或已有CI，不为埋点验收擅自调用付费模型。核对未同意/拒绝/排除时不发送GA、接受后才发送；结果轮询/重访不应重复上报同一待跟踪任务。调试先排除流量；验证采集时用专用浏览器解除排除并注明受控访问。

报告记录property、Measurement ID、时区、日期窗口、未定稿和内部流量限制。默认窗口可能截止昨天而属性今天才创建，不可把这种空表判为未接入。来源(not set)、渠道行和与总计不一致时保留原值，不编造渠道比例。
